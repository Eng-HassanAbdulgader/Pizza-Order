# 🍕 Pizza Order System

A simple desktop Pizza Ordering System developed using **C# and Windows Forms (.NET)**. The application allows users to customize their pizza, calculate the total price, review their order, and confirm or reset it through an interactive graphical user interface.

## ✨ Features

- **Pizza Size Selection:** Choose Small, Medium, or Large.
- **Customizable Toppings:** Add extra cheese, onions, mushrooms, olives, green peppers, and tomatoes.
- **Crust Selection:** Choose between thin and thick crust.
- **Dining Options:** Select Eat In or Take Out.
- **Dynamic Price Calculation:** Automatically update the total price based on the selected size, crust, and toppings.
- **Order Summary:** Display the selected pizza options and total price.
- **Order Confirmation:** Confirm the order through a dialog box.
- **Reset Functionality:** Reset the form to its default selections and start a new order.

## 🛠️ Technologies Used

- C#
- .NET Windows Forms
- Visual Studio

## 🎯 Learning Objectives

This project helped me practice C# fundamentals, Windows Forms controls, event handling, conditional statements, methods, and calculating prices based on user selections.
